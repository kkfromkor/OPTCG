# OPTCG runtime

OPCGPRO가 실행 중에 내려받는 공개 카드 데이터와 업데이트 매니페스트 저장소입니다.

- 운영 소유자: `kkfromkor`
- 비공개 개발 정본: `kkfromkor/opcgpro`
- 공개 런타임 저장소: `kkfromkor/OPTCG`

`cards-opcg.cdb`, `script`, `lflists`, `bin/ocgcore.dll`과 업데이트 매니페스트를 제공합니다. APK, IPA와 Windows 업데이트 ZIP은 Git 기록에 넣지 않고 GitHub Releases로만 배포합니다.

이 저장소는 포크가 아닌 독립 저장소이며 OPCGPRO의 런타임 운영 경로는 `kkfromkor`가 단독 관리합니다. 포함된 오픈소스 코드와 데이터의 원저작권·라이선스는 각 파일의 고지를 따릅니다.
